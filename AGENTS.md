# Fluxo de worktrees e publicação

- Crie cada worktree de trabalho a partir da `main` atualizada. Use a branch de trabalho para implementar e validar a entrega.
- Ao concluir, incorpore a entrega à `main`, confira o commit e faça push de `main` para `origin`. Verifique o commit no remoto.
- Depois de confirmar a integração, remova a worktree e sua branch temporária, incluindo a branch remota se tiver sido criada. Preserve trabalho que ainda não foi incorporado. A branch permanente é `main`.
